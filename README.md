# Metro Lisboa Live

**Acompanha o Metro de Lisboa, em tempo real.**

O **Metro Lisboa Live** é uma aplicação web que permite acompanhar a circulação do Metropolitano de Lisboa de forma simples, visual e intuitiva.

O objetivo é reunir num único lugar as previsões de chegada dos comboios, o estado das linhas e a informação das estações, tornando mais fácil perceber o que se passa na rede e planear as viagens do dia a dia.

## Funcionalidades

- **Mapa interativo da rede** — Visualiza as quatro linhas do Metro de Lisboa e acompanha o movimento estimado dos comboios diretamente no mapa.
- **Tempos de chegada em tempo real** — Consulta as previsões de chegada dos próximos comboios, com informação sobre os destinos e sentidos de circulação.
- **Acompanhamento por linha** — Explora as linhas Azul, Amarela, Verde e Vermelha, com as respetivas estações, previsões de chegada e circulação estimada dos comboios.
- **Estado da rede** — Consulta as informações de circulação disponibilizadas pelo operador e identifica possíveis perturbações no serviço.
- **Informação das estações** — Descobre os próximos comboios, correspondências entre linhas, horários de funcionamento e localização geográfica de cada estação.
- **Uma experiência adaptada a qualquer dispositivo** — Interface disponível para computador, tablet e telemóvel, com diferentes modos de visualização e temas claro e escuro.

## Dados em tempo real

As previsões de chegada dos comboios e as informações sobre o estado de circulação são obtidas através da **API oficial do Metropolitano de Lisboa**.

O Metro Lisboa Live utiliza estes dados para apresentar uma visualização dinâmica da rede, incluindo animações que representam o movimento dos comboios.

**Importante:** As posições apresentadas no mapa são estimativas calculadas a partir dos tempos de chegada fornecidos pelo operador. Não correspondem a localizações GPS nem representam necessariamente a posição física exata dos comboios.

A disponibilidade e atualização da informação dependem dos dados fornecidos pelo Metropolitano de Lisboa. Quando estes deixam de estar atualizados, a aplicação assinala essa situação.

## Sobre o projeto

O **Metro Lisboa Live**, desenvolvido no âmbito do projeto **Metro Motion**, é uma iniciativa independente que procura oferecer uma forma alternativa, moderna e acessível de consultar a informação da rede do Metro de Lisboa.

Este projeto não é uma aplicação oficial do Metropolitano de Lisboa.

Para informações, comunicados e avisos oficiais, consulta o [site do Metropolitano de Lisboa](https://www.metrolisboa.pt/).
